- [o] C6 — P1: ACP is removed from the room. Input: `src/engine.ts`, `src/room/acp-shapes.ts` and the dependency `soksak-plugin-agents-acp` in `plugin.json` implemented the room on ACP. Expected: the ACP code and the dependency are removed, and the message relay of C5 replaces them. Decision: C6 is done together with C2. A view cannot call a command of another plugin (`docs/spec/native-surfaces.md`, `runtime.command.run`), and `soksak-plugin-agents-acp` is still in the old manifest form, so ACP calls cannot work from the room page. Keeping them would fail at each send, so the room calls no ACP command. Result: removed `src/engine.ts`, `src/room/acp-shapes.ts`, `src/conversation.ts`, `src/room/envelope.ts`, `src/railBridge.ts` and their tests; removed the ACP system prompt shape of persona; removed the dependency `soksak-plugin-agents-acp` from `plugin.json` and `@agentclientprotocol/sdk` from `package.json`; removed the commands `send`, `ask` and `converse`, the elements `crown` and `modal`, and the settings `permissionPolicy`, `facilMaxRounds` and `nameTriggerDepthCap`. The transport status `soksak-plugin-agents-clubhouse.transport` is `unavailable` with its reason, and the composer is disabled, so the room shows its state and makes no call. The member transport returns with C3 (owned sessions) and C5 (terminal relay). Waits for: nothing.
